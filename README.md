# Flights-Delay-MLOps-Pipeline

## Description du projet
Ce projet vise à prédire les retards de vols aux États-Unis à partir de données de vols historiques.
Mini-pipeline MLOps pour prédire les retards de vols et inclut : 
* Préparation et nettoyage des données (data cleaning)
* Transformation et encodage des variables (data processing)
* Selection de features et entraînement du modèle ML
* Évaluation et interprétation des performances
* Versioning avec DVC, automatisation CI/CD
* Déploiement via FastAPI et Docker
* Monitoring des performances.
